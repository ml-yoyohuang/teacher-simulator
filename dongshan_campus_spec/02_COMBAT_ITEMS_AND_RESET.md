# 02｜操作、戰鬥、26種道具與場景恢復

## 1. 輸入定案

手機：左虛擬搖桿、右攻擊/閃避、情境互動；手持可投擲物時多一個投擲鍵。按鈕至少48 CSS px，常用56–64px，safe-area內佈局。最多兩個持續觸點，一根手指移動、一根操作。Pointer Events追蹤pointerId、capture/cancel，不混合touch與click重複觸發。UI點選不穿透到戰場；失焦、開選單、暫停清空輸入。

桌機：WASD/方向鍵移動；J或滑鼠左鍵攻擊；K或Space閃避；E互動；Q投擲；R放下；Esc暫停。滑鼠在世界上只決定面向（地面射線），不要求自由鏡頭。鍵位在說明頁顯示。對話/商店開啟時停止戰鬥輸入。

一次攜帶一件物品，沒有戰鬥揹包。眼鏡/假髮是獨立頭部裝飾位，各最多一件；能戴著裝飾拿掃把，不憑空複製裝飾。任務考卷用bundle物件承載3份，不建複雜揹包。UI按住互動可開小選單（拿取/放下/戴上/歸還），鍵盤有等效選項。最多列3–4個選項，預設優先當前任務行為。聊天、購物、長動作可取消，附近追逐者不因對話永遠凍住（真正暫停選單才凍結世界）。

## 2. 戰鬥預設

所有數字可由實測調整，寫入單一balance設定與DECISIONS，保留角色定位。
- 玩家體力100；走3.2m/s、跑4.6m/s（搖桿推深或Shift，無額外精力條）。
- 空手傷害10、距離1.2m、扇形80度、冷卻0.45s；每次揮打最多3目標，不穿牆。
- 閃避位移2.2m/0.25s、冷卻1.4s、短無敵0.15s；沿路掃掠碰撞，不能跨牆。
- 受擊無敵0.65s，擊退有上限，避免多NPC鎖到死；控制效果不無限續接。
- 學生耐力25–40，教師50–70，家長65–110，家長會代表120。NPC攻擊6–12，高階大招16–20，傷害有前搖與恢復期。
- NPC倒地約6–10s、恢復耐力起身；本次事件記憶保留，不每次起身重複叫家長。重新站起至少2s非攻擊期。
- 家長擊倒後暈眩、起身離場，不直接再次追逐同一波。
- 普通角色不主動超遠攻擊。投擲物有碰撞、有可見前搖/飛行，不以全圖必中取代。

擊中根據動畫active frame做判定；一次attackId每目標只能命中一次。動畫不是真實傷害來源。投擲同樣有projectileId與首次有效命中標記；彈跳物可再命中但至少0.4s間隔且最多2次有效命中。玩家拿起物品停止其飛行狀態。

輔助瞄準：面向前方約70度、8m內選可見最近威脅；沒有適合目標就按面向丟擲。優先規則可切為人物/場景但不用精準點選小人物；禁對牆後目標吸附。羽球拍拍回輕型投擲物有約0.3s寬鬆視窗，用近身扇區判定與提示，不能要求毫秒反應。

人物失去耐力不掉錢，沒有靠無限打NPC買升級的經濟迴圈。玩家可自由選擇逃離或迎戰。

## 4. 物件身份與任務規則

每件有instanceId、typeId、homeTransform、zoneId、ownerId、state、questPins；state唯一值home/held/worn/airborne/settled/damaged/reserved，不能同時在手上和出生點。角色只持itemId，持有者消失時先交還物件。

拿取與交接是一個原子操作：檢查可拿→解除舊持有/碰撞→更新身份→附手部節點。歸還按既有ID回home，不能另造一件。將物件投入任務區時先完成交付，再轉狀態。裝飾獎勵不用偷來的同一instance充當永久收藏。

## 5. 恢復與保健室

離開zone至少45s、玩家>20m、無活躍追逐、無鏡頭可見、無questPins才可歸位。通常一區一批恢復，避免剛離鏡頭傢俱瞬移。

持有、佩戴、NPC持有、飛行中、任務保留物件不歸位。NPC移出活躍區時儲存持物身份或放下，不刪除。任務物品卡在無法走到的地方時，提供「重置此任務物品」功能，先解除身份再安全放到任務取物點，不復制。

空地碎片2–4s消退；可回收道具是獨立實體不隨碎片消失。破損傢俱保留碰撞到zone重置，必要時有扶起動作。可破壞不等於實時幾何切割。

玩家耗盡體力：轉場→保健室100HP→丟下攜帶/返還佩戴→全場騷動清理→警戒0、家長撤離→未完成任務重回可重試狀態，已完成持久紀錄不倒退。報告列本次破壞、暈眩、被追逐家長、最高警戒，均來自事件而非隨機文案數字。

主動休息：僅警戒0且沒有追逐時可用校護恢復。警戒中走進保健室不會免費消除通緝：入口提示「先甩開追逐再來」，只有倒地救援會強制轉送。這避免安全區無限躲一下就洗警戒；追逐者永不進入休息房。


### 保健室入口補充

主動進入休息區需要警戒≤1、沒有Chase與Search家長/教師；條件不符時門口互動拒絕進入，玩家仍在走廊，不建立可穿越的無敵邊界。警戒0才可與校護主動恢復體力；倒地救援不受入口條件限制。休息區不是對所有人物永久關閉的場景。
