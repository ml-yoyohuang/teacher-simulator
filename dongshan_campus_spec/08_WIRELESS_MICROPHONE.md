# 08｜校園無線麥克風增補（2026-10-08）

本文件追加使用者後續規格，優先於原版本1.0的固定26道具數量；不覆寫已完成的開心導師名稱、2.2倍手機鏡頭、擊倒圖鑑及可收合TODAY提示。基礎道具現為27種，另有8種任務／NPC衍生物；內容清單由資料重新計算。原有40任務與活動系統維持。

- ID `wireless_microphone`，名稱「校園無線麥克風」，描述「請注意廣播。老師目前非常冷靜。」。一般日音樂教室器材架旁，所有目前有舞臺的活動日在中庭舞臺右側器材位置；每模式一個同ID物件。
- 輕型，揮打6、投擲8、1.2m揮打距離、0.45秒攻擊冷卻。共用拿取、放下、投擲、歸還及不可見場景恢復；一次只持一件。原創深灰握柄、低分段灰藍網罩、黃色環带，底面pivot、材質／幾何合批，與碰撞分離。
- 手持「動作」選單增加擴音點名，沿用F與既有點名入口，不新增常駐鍵。半徑10m、一般点名6m，共用12秒冷卻；學生先轉頭0.35秒再集合。不操控反擊、暈眩、逃跑、通話或重要任務狀態，不召集家長／訪客，不洗警戒與記憶。以墙壁視線檢查限制可聽範圍。
- 玩家投擲第一次停止飛行時，播放3秒廣播；一個flight ID只啟動一次，普通放下不啟動，空中接回即取消。拿回（含NPC拿取）、歸還、物件移除、重置、救援及模式切換清除廣播。落地保持麥克風可用與唯一身份。
- 廣播聲響範圍10m，牆阻擋；平靜人物與失去老師視線的Search人物可調查，Chase／Attack仍保留目標。目擊投擲追逐者記住當次flight誘餌；護子、通話、搬回物品、入場、座位、合唱／致詞等重要工作忽略。不是全圖指令。
- 同NPC／同instance麥克風30秒調查冷卻，只有接受有效尋路開始調查才消耗。沿既有0.75m格網與路徑預算，不走直線穿牆或瞬移；不可達不接受，路線失效／卡住停止。再次看見老師立即恢復追逐，lastSeen保留；調查耗時算入原Search計時，廣播結束回原狀態，不直接完成甩開或額外生成家長。
- 廣播與提示採遊戲時鐘，暫停／背景停止，恢復不重播起音。Game聲響與Audio播放分離，靜音仍有效。使用原AudioEngine與12音效／6音樂聲部，廣播音源帶flight標籤，取消即停止；試聽頁同步新增起音與提示音。
- 生存時間有界：廣播最多3筆（一般實際1支）、舉麥提示1秒、每廣播最多2道動態波紋+一個靜態圈、最多一個可見文字氣泡；減少動畫僅保留必要靜態提示。無真人配音、錄音、裝置麥克風權限、語音辨識、回授暈眩或新任務。
- 驗證見`tests/microphone.test.ts`、`scripts/microphone-qa.ts`、`QA_REPORT.md`與artifacts，包含真實追逐／遮擋／搜索／調查／離開及目擊投擲不受騙演示。實體手機、Safari與人工聽感不宣稱已測。
