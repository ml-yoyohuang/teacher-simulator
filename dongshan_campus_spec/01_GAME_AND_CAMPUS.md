# 01｜遊戲定位、主角與校園

## 1. 定案

正式暫定名「東山校園大騷動」，開發代稱「東山國中 GTA」。這是虛構、非血腥、荒謬搞笑的校園3D沙盒；不調查或重建真實學校，不使用真實校徽、地址、學生、教師姓名、肖像或精確平面圖，不使用GTA商標素材。名稱保留使用者的創作意圖，開始畫面附簡短「虛構校園與角色」說明，不製作冗長警告頁。

樂趣：自由探索→搬動與破壞物件→人物依性格反應→學生通知家長或教師→追逐與簡單戰鬥→利用地形甩開→恢復秩序→再次嘗試。任務與活動是可選目標，不是自由玩法的入口門檻。

平臺：本地可啟動、靜態可部署的網頁，手機觸控優先，桌機鍵鼠完整支援。單人、無後端、無帳號、無付費、無廣告、不需要線上排行榜。可以合成音樂音效。真正3D，Y軸垂直，人物主要在XZ平面移動。

## 2. 開心導師

ID player_music_teacher，角色名「開心導師」。成年女教師，是班導，主教音樂。棕色鮑伯頭；黃色有領短袖洋裝，裙長至小腿；簡單深棕平底鞋。全程面無表情、姿態優雅，靠動作與他人反應製造喜劇。主角不是轉學生、吉祥物或一般學生，不能自行替換身份。

動畫：端正站立、整理衣領、從容走、快步跑、揮拳、揮工具、投擲、拾取、放下、短距閃避、跌坐、起身拍裙、點名、鋼琴教學、戴假髮整理。裙子使用簡單剛性／骨架擺動，不做布料模擬。能力不靠刷等級解鎖。

對白示例：「請不要在走廊奔跑。」「這是節奏練習。」「物品使用完畢，請歸位。」「各位家長，歡迎。」「我們正在進行跨領域教學。」每句有播放冷卻，用文字氣泡，不需配音。

老師技能：
- 點名：互動選單的專用動作，呼叫附近可聽見學生靠近集合，半徑6m、冷卻12s。正在暈眩、反擊、高警戒逃跑者不一定服從。無傷害、無全圖瞬移。
- 假裝上課：站到講臺或鋼琴互動，只有警戒0–1且未被追逐者看見時才可降低疑心。目擊搗亂者不被立即洗去記憶。
- 外觀：預設主角造型不可變，獎勵僅加徽章、眼鏡、鞋配色等小裝飾；黃色洋裝與棕色鮑伯頭不被隨機裝扮覆蓋。偷戴假髮是暫時狀態。

## 3. 鏡頭與移動

正交固定斜俯視鏡頭，方位約45度，俯角約50–55度；跟隨玩家，有阻尼，不能旋轉。橫豎螢幕都可玩，橫向較開闊。視野以玩家周圍約18–24m為起點依實測調整。攝影機不穿樓、不因高牆遮住角色，屋頂與近側牆以分組淡出／隱藏，不能一律把整棟樓消失。必要時玩家與關鍵目標有遮擋輪廓提示。

輸入方向按鏡頭平面換算，推上就是畫面上。開門觸發器和走廊出口連續，沒有第一人稱或鏡頭操作需求。

## 4. 地圖

一個連續、單層小校園；10個命名區域，建築共用走廊，不製作獨立大型建築給每個房間。無城市、車輛、屋頂攀爬、地下室、多樓層。

建議可重現的平面：世界範圍約x[-32,32] z[-26,26]，正z為校門方向。房間尺寸與出生點是預設可微調，不是藝術死限制。

保健室入口連到走廊，不能當跨區瞬移點。合作社視窗沒有完整大商場。活動舞臺設在中庭預留空間，沿用校園，不新增大型禮堂。

## 5. 模式與遊玩程序

首次開場在導師辦公室。日常差事教學約3–5分鐘，可跳過、重看：移動→拿考卷→送教室→迴音樂室→練習區揮打/投擲→閃避→腳印示意追逐→藏到工具間→檢視任務與行事曆。教程用練習假人，不要求攻擊人物。可在任一步跳過，全部內容立即開放，跳過不影響後續任務物件。

一般校園自由遊玩；今日待辦一次追蹤一項任務，取消無懲罰。可透過行事曆選活動。固定顯示順序「親師日、校慶、合唱團比賽、期末考」，教學完成或跳過後自由選，沒有逐章解鎖。

活動切換/退出是明確場景重置，顯示確認；結束當前追逐、重置物件與NPC、取消不適用任務、保留長期紀錄。不是單靠換活動免費領補給或刷點。

玩家體力耗盡到保健室，結束本次騷動，有一份真實統計的事件報告。校園重置，點數、已完成任務、已買外觀、活動紀錄保留。沒有死亡、血跡、肢解或永久人物傷亡。

## 6. 整體體驗底線

每個區域至少三種有用途的互動。主角和NPC分別有體力與暈眩狀態；破壞以翻倒、裂開、紙片等喜劇效果表現。人物短暫跌坐起身，無寫實傷勢。學生、家長、教師可被擊退，但校護/保健室處於休息保護範圍。合作社和校門人物有專屬反應，不是隻做一個通用追逐NPC換衣。
